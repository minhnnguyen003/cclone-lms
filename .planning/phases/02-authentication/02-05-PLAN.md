## Diagnosis

**Root cause:** `@vitejs/plugin-react@4.x` is incompatible with Vite 8 / Rolldown. When the plugin detects `rolldownVersion` in the Vite environment, its `config()` hook returns `{ rollupOptions: { jsx: { mode: "automatic" } } }`. Vite 8 forwards `rollupOptions` to `rolldownOptions`, so `jsx` ends up as a top-level `InputOption`. Rolldown 1.0.0-rc.15 removed `jsx` from `InputOptions` (it now belongs in `TransformOptions`), causing Rolldown to emit:

> Warning: Invalid input options (1 issue found) — For the 'jsx'. Invalid key: Expected never but received 'jsx'.

**Fix:** Upgrade `@vitejs/plugin-react` to `^6.0.1`. v6 is Vite 8-only and Rolldown-native — it does not set the legacy `jsx` InputOption. The import path remains `@vitejs/plugin-react` and the `react()` call in vite.config.ts is unchanged. There is no need to switch to a different package.

**Why not @vitejs/plugin-react-oxc:** That package declares a peerDependency of `vite: "^6.3.0 || ^7.0.0"`, which excludes Vite 8. Installing it would produce a peer dependency conflict and would not reliably fix the warning.

**No behavior change for auth features:** The upgrade only changes how JSX is transformed internally. React Runtime mode (automatic) remains the default. All existing React components, hooks, and routing behaviour remain identical.
