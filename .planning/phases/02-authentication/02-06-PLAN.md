From apps/frontend/src/lib/axios.ts (request interceptor):
```typescript
api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().accessToken;
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});
```
The interceptor calls `useAuthStore.getState()` at request time — it reads the live mock
return value at the moment the request fires, not when the module was loaded.

Current broken axios.test.ts beforeEach sequence (WRONG ORDER):
  1. vi.resetModules()
  2. await import('@/lib/axios')       <-- fresh module loaded, interceptors registered
  3. vi.clearAllMocks()                <-- BUG: wipes mockGetState's return value
  4. mockGetState.mockReturnValue(...) <-- restores return value, but damage done for some tests

The Bearer token test ("attaches Bearer token") adds its own spy AFTER beforeEach completes.
When that spy fires, it calls config.headers.Authorization — which was set by the request
interceptor at request time. The interceptor calls mockGetState() which, due to the ordering
above, sometimes sees undefined if clearAllMocks ran between module load and the test body.

ROOT CAUSE: vi.clearAllMocks() belongs in afterEach (post-test cleanup), not in beforeEach
(pre-test setup). In beforeEach you want mocks SET, not cleared.

```typescript
  beforeEach(async () => {
    // Reset window.location mock for redirect tests
    Object.defineProperty(window, 'location', {
      writable: true,
      value: { ...originalLocation, pathname: '/dashboard', search: '', href: '' },
    });

    // Clear module cache to get a fresh axios instance with clean interceptors
    vi.resetModules();
```
